# Scheduled Task Worker & Pipeline Runner

A lightweight automated pipeline utility designed for scheduled environment execution and periodic data synchronization tasks.

## Overview
This repository contains automated CI/CD workflow configurations and container runtime routines for headless task processing and distributed data telemetry.

## Features
- Containerized execution environment
- Automated scheduled event triggers
- Configurable environment variable hydration
- Telemetry logging and health reporting

## Environment Setup
Run containerized tasks locally:
```bash
chmod +x run.sh
./run.sh
```
